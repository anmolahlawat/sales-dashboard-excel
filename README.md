# 📊 Excel Sales & Performance Dashboard

A professional Microsoft Excel dashboard built using Pivot Tables, Pivot Charts, KPI Cards, XLOOKUP, SUMIFS, COUNTIFS, and interactive slicers to analyze sales performance and business metrics.

---

## 📌 Project Overview

This project demonstrates end-to-end sales data analysis in Microsoft Excel.

The raw dataset was cleaned, transformed, analyzed, and visualized into an interactive dashboard for business decision-making.

---

- Data Cleaning

- Pivot Charts
- XLOOKUP

- Sales Trend Analysis
